## 🧠 Actividades realizadas en clase

Durante la sesión se trabajó en el análisis e integración de las cinco vistas arquitectónicas del caso FarmApp, una cadena de farmacias con sistema de e-commerce integrado. Como equipo se discutió la relación entre las capas de negocio, información, aplicaciones, infraestructura y seguridad, buscando mantener coherencia entre cada una de ellas.

Se tomaron decisiones relacionadas con la forma en que los procesos de negocio debían conectarse con las entidades de información y los sistemas tecnológicos. También se definió el uso de un API Gateway centralizado como punto de comunicación entre aplicaciones y se identificó la importancia de la replicación de bases de datos para mantener sincronizado el inventario entre los distintos canales.

Para el desarrollo del taller se utilizaron herramientas digitales de diagramación y documentación para estructurar las vistas arquitectónicas y organizar el contenido del informe. Durante la sesión se alcanzó a desarrollar la descripción del caso, las cinco vistas arquitectónicas, las relaciones entre capas y el análisis de coherencia arquitectónica.

## 🧩 Boceto inicial del modelo

> Se realizó un esquema inicial de la arquitectura de FarmApp identificando la interacción entre clientes, aplicaciones, sistemas de información, infraestructura en nube híbrida y mecanismos de seguridad. Posteriormente este boceto fue llevado al informe final y diagramas digitales.
